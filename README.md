# 轨迹去噪与状态估计（基于 Mamba）

本实验为 exp2 的变体，目标改为去噪/状态估计：给定时刻 t 的带噪测量，预测时刻 t 的真实位置。


在仓库根运行：
```powershell
python .\exp2\exp3\train.py
python .\exp2\exp3\eval.py
python .\exp2\exp3\visualize.py
```
